#### Project: Atelier Store

#### Structure

* /backend: API and server logic
* /frontend: Client-side user interface

#### Tech Stack

* **Backend**: Java Spring Boot
* **Frontend**: Angular 21

#### Workflow Rules

* Always check which directory (backend or frontend) a file belongs to before editing.
* Work on one folder (backend or frontend) at a time.
* Keep changes small, modular, and explain commands before running them.
